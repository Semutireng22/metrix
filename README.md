# Proyek MaitrixAI

## Persiapan Awal

1. Clone repositori dari GitHub:
```bash
git clone https://github.com/Semutireng22/metrix.git
cd metrix
```

2. Install semua dependensi yang diperlukan:
```bash
npm install
```

3. Konfigurasi file .env:
```bash
nano .env
```
Isi file .env dengan konfigurasi yang diperlukan:
```
RPC_URL=your_rpc_url
PRIVATE_KEY=your_private_key
```

4. Jalankan aplikasi:
```bash
node main.js
```
Atau jika menggunakan script npm:
```bash
npm run start
```

## Catatan
- Pastikan Node.js dan npm sudah terinstall di sistem Anda.
- Jangan lupa untuk mengisi file .env dengan konfigurasi yang valid.
- Untuk bantuan lebih lanjut, silakan buka issue di repositori GitHub.
